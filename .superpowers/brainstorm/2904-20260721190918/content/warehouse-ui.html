總倉庫存量 — UI 顯示設計

DrugCard（掃描清點卡片）與 PreviewPanel（匯入預覽）兩處都要顯示 warehouse_quantity

DrugCard 掃描卡片：三個方案

A

與數量欄並排顯示

預期數量旁直接顯示倉庫存量，一行內呈現完整數字資訊。

B

獨立一行小字

卡片底部用較小字體、較低對比度顯示倉庫存量，不干擾主清點流程。

C

可折疊/展開資訊區

預設隱藏，點擊展開才看倉庫存量。手機小螢幕友善。

方案選擇

A

卡片 A（並排）+ 預覽表格新增欄位 (Recommended)

清晰直觀，一眼看到三組數字關係。最符合藥局現場快速掃描的需求。

B

卡片 B（小字獨立行）+ 預覽表格新增欄位

卡片保持簡潔，倉庫存量不搶眼。適合不想被額外數字干擾的使用者。

C

卡片 C（可折疊）+ 預覽表格新增欄位

手機小螢幕最省空間，但多一步操作才能看到存量。
