## 基礎功能驗收

### 1. AI 設定開關
- [ ] 進入 `/scan?manifestId=xxx` 頁面
- [ ] Header 右側顯示「齒輪圖示」
- [ ] 點擊齒輪 → 彈出設定面板
- [ ] 面板顯示「啟用 AI 計數模式」核取方塊
- [ ] 面板顯示當前模式：`🟢 WebGPU` 或 `🟡 CPU (WASM)`
- [ ] 勾選核取方塊 → 面板關閉，Header 顯示 AI 模式指示器
- [ ] 取消勾選 → AI 模式關閉，指示器消失

### 2. 模型載入流程
- [ ] **Phase 1**: 進入 `/scan` 頁面 → 背景自動下載 Decoder (~4MB)
- [ ] **Phase 2**: 點擊任一藥品「拍照確認」 → 背景下載 Encoder (~35MB)
- [ ] **Phase 3**: 照片載入完成 → 顯示「AI 模型分析中...」→ 完成後可點擊
- [ ] 全程 UI 不阻塞，可繼續操作其他功能

### 3. 拍照/選圖流程
- [ ] 點擊藥品卡片「拍照確認」按鈕
- [ ] CameraModal 開啟，顯示相機預覽或「從相簿選擇」
- [ ] 選擇測試照片 / 拍照完成
- [ ] 照片顯示在 Modal 中，`object-contain` 保持比例
- [ ] AI 模式開啟時，右上角顯示「AI 計數模式」指示器

### 4. AI 分析與點擊計數
- [ ] 照片載入後，等待 Encoder 完成 (顯示載入動畫)
- [ ] 載入完成後，滑鼠/手指點擊相片上的藥物
- [ ] 點擊位置立即出現 **Ripple 波紋動畫** (視覺回饋)
- [ ] < 30ms (WebGPU) / < 80ms (WASM) 內出現：
  - 半透明綠色 Mask 覆蓋 (`rgba(0,255,120,0.35)`)
  - 數字標籤 `①` `②` `③`... 置於 Mask 中心
- [ ] 底部 Sticky Bar 即時顯示：`AI 偵測顆粒數: N 顆`

### 5. 重複點擊去重
- [ ] 連續點擊同一顆藥物 2 次
- [ ] 第 2 次點擊被忽略 (IoU > 0.75)，計數不增加
- [ ] 無錯誤提示，UI 保持平滑

### 6. 負向點擊 (刪除誤判)
- [ ] 右鍵點擊 / 長按 (行動裝置) 已存在的 Mask
- [ ] 該 Mask 連同數字標籤立即消失
- [ ] 計數 -1，剩餘標籤重新編號 (①②③...)
- [ ] 歷史堆疊記錄此操作，可 Undo

### 7. 底部操作列
- [ ] **復原 (Undo)**: 撤銷最後一次點擊/刪除，可連續復原
- [ ] **清空全部**: 移除所有 Mask，計數歸零，歷史堆疊重置
- [ ] **採用 AI 結果 (N)**: 按鈕高亮可點擊，點擊後：
  - Modal 關閉
  - 對應藥品的 `actual_quantity` 更新為 N
  - 既有上傳流程繼續執行

### 8. 座標精準度 (Edge Case 1)
- [ ] **Retina 螢幕** (MacBook/iPhone): 標籤位置精準，無偏移
- [ ] **直向長圖**: 上下留白區域點擊不誤判
- [ ] **橫向寬圖**: 左右留白區域點擊不誤判
- [ ] **縮放比例變化**: 視窗調整大小後點擊仍精準
