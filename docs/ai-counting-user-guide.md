# AI 智能計數使用指南

## 概述

PhamaCount Web 整合了 **MobileSAM/EdgeSAM** 邊緣 AI 模型，提供**完全離線、毫秒級回應、零伺服器成本**的藥物顆粒自動計數功能。使用者只需在拍照確認時點擊藥物，AI 即可自動偵測並標記計數。

---

## 啟用方式

1. 進入清點頁面 (`/scan?manifestId=xxx`)
2. 點擊右上角 **齒輪圖示** ⚙️
3. 勾選 **「啟用 AI 計數模式」**
4. 系統顯示當前運算模式：
   - `🟢 WebGPU` - 顯卡加速 (Chrome/Edge，<30ms)
   - `🟡 CPU (WASM)` - 相容模式 (Firefox/Safari/iOS，<80ms)

> **首次使用**：需下載模型檔案 (~39MB)，建議在 WiFi 環境下載。下載完成後會自動快取，**之後離線也能使用**。

---

## 操作流程

### 步驟 1：開啟拍照
點擊任一藥品卡片的 **「拍照確認」** 按鈕

### 步驟 2：拍照或選圖
- **拍照**：點擊底部白色圓形按鈕 📷
- **從相簿選擇**：點擊「從相簿選擇」按鈕

### 步驟 3：等待 AI 分析
- 照片載入後，系統自動執行 AI 分析 (顯示「AI 模型分析中...」)
- **Encoder 全圖特徵提取** 只需執行一次 (~600ms WebGPU / ~1.8s WASM)
- 分析完成後，相片上方會出現 **AI 計數模式** 指示器

### 步驟 4：點擊計數
- 在相片上 **左鍵點擊** 每一顆藥物
- 點擊位置立即出現 **波紋動畫** 回饋
- AI 瞬間產生 **綠色半透明 Mask** + **數字標籤 ①②③...**
- 底部即時顯示：**AI 偵測顆粒數: N 顆**

### 步驟 5：修正誤判 (可選)
- **刪除誤判**：**右鍵點擊** / **長按** (手機) 已標記的 Mask → 立即刪除
- **復原操作**：點擊底部「復原」按鈕 ↩️
- **清空重來**：點擊底部「清空全部」按鈕 🗑️

### 步驟 6：採用結果
- 確認所有藥物都已正確標記
- 點擊底部綠色按鈕 **「採用 AI 結果 (N)」** ✅
- 系統自動：
  1. 關閉拍照視窗
  2. 將計數 N 填入該藥品的「實際數量」
  3. 繼續原有上傳流程 (上傳照片、更新資料庫)

## 注意事項

### ⚡ 效能建議
- **連續拍照** 請間隔 2-3 秒，避免記憶體壓力
- iOS Safari 使用 CPU 模式，速度稍慢但功能完整
- 大量藥物照片建議在光線充足、背景單純環境拍攝

### 📱 行動裝置操作
- **點擊計數**：手指輕觸藥物中心
- **刪除誤判**：手指**長按** 1 秒該標記
- **縮放/平移**：雙指捏合/拖曳 (不影響 AI 座標精度)

### 🔒 隱私與離線
- **零上傳**：所有 AI 運算在瀏覽器端完成，照片不上傳雲端
- **離線可用**：模型首次下載後永久快取，斷網可用
- **無追蹤**：不記錄使用者點擊行為或圖片內容

### 🎯 最佳拍攝條件
- 光線均勻，避免陰影遮蓋藥物
- 攝影距離：藥物佔畫面 30-50%
- 背景單純 (白紙/淺色桌面)
- 藥物間距明顯，避免重疊過度

## 常見問題 (FAQ)

### Q: 點擊後沒有出現標籤？
A: 確認 AI 分析已完成 (載入動畫消失)、模式指示器顯示綠色。若仍無反應，嘗試重新整理頁面。

### Q: 標籤位置偏移？
A: 此為 High-DPI 螢幕相容性問題，請回報給開發團隊並提供裝置型號。

### Q: 計數錯誤 (漏數/多數)？
A: 使用「刪除誤判」移除錯誤標籤，重新點擊正確位置。嚴重重疊藥物建議人工計數。

### Q: iOS Safari 很慢？
A: iOS 不支援 WebGPU，自動降級 WASM 模式 (~80ms/次)，屬正常現象。

### Q: 怎麼知道模型有沒有快取成功？
A: 斷網重新整理，若 AI 設定面板**不顯示「載入中...」**且可直接勾選，表示快取成功。

### Q: 可以自訂模型嗎？
A: 目前支援 MobileSAM/EdgeSAM，未來版本將支援模型熱更新 (SW stale-while-revalidate)。

## 技術規格摘要

| 項目 | 規格 |
|------|------|
| 模型架構 | MobileSAM (Encoder + Decoder) |
| 量化格式 | INT8 / FP16 ONNX |
| 檔案大小 | Encoder ~35MB, Decoder ~4MB |
| 推論後端 | WebGPU (優先) → WASM+SIMD (降級) |
| Encoder 延遲 | < 600ms (WebGPU) / < 1.8s (WASM) |
| Decoder 延遲 | < 30ms (WebGPU) / < 80ms (WASM) |
| 記憶體佔用 | ~50-100MB (含模型) |
| 離線支援 | ✅ 完整離線 (Service Worker 快取) |
| 隱私等級 | 🔒 端側運算，零資料上傳 |
